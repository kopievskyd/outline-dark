<h1 align="center">Outline Dark</h1>

<p align="center">Dark Firefox theme with toolbar outlines and a filled active tab</p>

![Screenshot](assets/screenshot.png)

## Build

```sh
zip --junk-paths outline-dark.xpi manifest.json
```
